# CityTrace 使用手册

本文按实际界面操作说明。还没启动项目，请先回到 [README](../README.md#quick-start)。手机访问和 HTTPS 的设置见[部署手册](DEPLOYMENT.md)。

## 1. 先理解几个概念

| 名称 | 含义 |
|---|---|
| GPS 记录 | 你实际行走时采集的位置、时间和精度；原始数据默认私有 |
| 路线草稿 | 将一次已结束的 GPS 记录整理为路书，尚未公开 |
| 标记点 / 打卡点 | 路线里按顺序排列的地点，可有名称、说明、照片、位置和停留信息 |
| 路段 | 两个相邻地点之间的一段行程，记录交通方式及可选用时、线路说明 |
| 公开路线 | 作者提交并由管理员审核通过的版本 |
| 复刻行程 | 某位用户按公开版本重新体验的独立行程；有自己的进度和 GPS |

**记录完成不等于发布成功；确认全部站点也不等于自动结束复刻。**分别需要保存草稿、提交审核和完成复刻。

## 2. 登录与注册

1. 点击右上角“登录 / 注册”。手机上同样从页面顶部进入。
2. 已有账号选择“登录”；新用户选择“注册”。
3. 注册时填写昵称、有效邮箱格式和至少 8 位密码。
4. 登录后右上角变为头像，可进入“我的”。
5. 退出使用“我的 → 退出登录”。网络失败时会提示“尚未退出登录”，不要把错误提示当作已退出。

演示账号仅在演示模式创建。真实模式下先由部署者创建管理员，再由普通使用者自行注册；普通注册不会获得管理员权限。

## 3. 导航与页面

电脑用左侧导航，手机用底部五个入口：

| 页面 | 主要操作 |
|---|---|
| 发现 | 查找公开路线，点卡片进入详情 |
| 地图 | 查看本页公开路线的轨迹及路线列表 |
| 记录 | 开始、暂停、继续、结束自己的 GPS 记录 |
| 行程 | 在“我的路线 / 已收藏 / 复刻记录”之间切换 |
| 我的 | 查看账号、进入路线分类、退出或停用账号；管理员可进入审核工具 |

### 发现与地图

- 在搜索框输入路线、城市或体验关键词；结果会更新，输入框保留焦点。
- 城市输入框单独限定城市；主题和时长可一起筛选。
- 没有结果时，用“清除筛选”恢复。
- 路线较多时，列表底部有“上一页 / 下一页”；地图页同样有分页。
- 未启用高德时看到的是坐标示意，不是道路地图。即使线条看起来通畅，也不表示有相应道路。

### 路线详情

点开一张路线卡片后，可以查看：

- 行程时长、距离和站点数量。
- 真实记录轨迹的公开版本。
- 按顺序排列的地点、说明、现场照片与相邻路段交通方式。
- 收藏、开始复刻、分享和站点的外部地图入口。

点时间轴地点可与地图标记联动。点照片可放大，再点遮罩或关闭按钮退出；键盘可用 Enter 打开、Escape 关闭。

## 4. 完整流程：账号 A 记录并发布一条路线

### 4.1 开始前准备

先确认：

1. 使用自己的注册账号。
2. 手机已经打开部署者提供的、设备信任的 HTTPS 地址。
3. 系统定位服务与浏览器位置权限开启。
4. 页面保持在前台，网络可用于开始记录及后续同步。

电脑通过 `localhost` 或 `127.0.0.1` 可测试定位，但电脑定位不能替代真实手机实走。没有高德 Key 也能记录 GPS；区别是没有道路底图。

### 4.2 记录真实行程

1. 打开“记录”，点击“开始记录”。
2. 浏览器询问位置权限时选择允许。取得可用位置后才创建记录。
3. 开始实际行走，查看计时、定位精度、移动距离、服务端已保存采样和本机待同步采样。
4. 需要停止采样时点“暂停”，准备继续时点“继续”。
5. 走完后点“结束并保存”，等待同步与保存成功。
6. 成功后进入路线编辑页面。此时路线仍是**私有草稿**。

若离线或还有采样未确认上传，暂停/保存可能不能完成。页面会保留队列并提示原因；恢复网络后再操作，不要以为按钮点过就已经保存。

为了演示发布流程，建议先走一段足够长的真实路线，例如约 600–1,000 米。公开时两端各裁剪约 150 米，短路线或异常采样过多时，裁剪后可能没有可公开轨迹。这里的建议距离不代表一定能通过发布检查。

离开记录页浏览其他页面时，可通过顶部的未结束记录提示返回。关掉整个页面或锁屏会有定位中断风险，无法补回没有采到的 GPS。

### 4.3 填写路线信息

在“编辑你的路线”中：

1. 填写路线名称。
2. 填写城市，选择主题。
3. 补充路线介绍：适合人群、实际体验、绕行情况等。
4. 需要封面时上传封面照片。
5. 点击“保存路线信息”，看到成功提示后再继续。

**提交审核不会替你保存还没点保存的名称、城市和简介。**封面上传与文字保存是不同操作。

### 4.4 添加沿途地点

以三个地点 A、B、C 为例：

1. 找到“沿途打卡点”。
2. 填写打卡名称和类型。
3. 选择真实位置：
   - 从“历史轨迹选点”选择采样位置；当前下拉最多列出前 120 个原始轨迹采样。
   - 或使用“定位”，将当前位置作为地点位置。
   - 已启用道路底图时，也可用“在轨迹地图上选点”。
   - 事后补录可以手填经纬度，但必须采用实际位置。
4. 填写推荐体验、消费、停留时间和现场说明；不需要的可留空或保持 0。
5. 点击“添加打卡点”。
6. 重复添加 B、C。

注意纬度和经度不能填反。手动输入默认按 WGS84 处理；不要把不清楚坐标体系的其他地图坐标直接粘贴进来。地图选点会记录相应的坐标来源和坐标体系。

表单里的“路线顺序”从 **0** 开始：0 是第一站，1 是第二站。地点列表展示通常从第 1 站开始计数。更直观的调整方式是保存后使用上移、下移按钮。

### 4.5 给每个地点上传照片

1. 在已保存的地点行找到“照片”。
2. 选择该地点的现场图片；支持多张。
3. 等待上传进度结束及成功提示。
4. 对每个地点重复操作。

支持 JPEG、PNG、WebP，每张最大 8 MB。服务端会清理常见 EXIF 等元数据，但照片画面本身仍需本人检查。浏览器是否提供直接拍照入口，由设备和浏览器决定。

**路线封面不能代替每个地点的现场照片。**发布要求每个地点至少一张照片。新建的测试点也要满足这个条件。

### 4.6 确认相邻路段

三个地点 A、B、C 会形成两个路段：A → B、B → C。

1. 找到“相邻标记点之间的交通”。
2. 为第一段选择“步行”，填写实际已知用时和说明，点击“保存本段方式”。
3. 为第二段选择“地铁”等实际方式，填写线路/站点信息，再保存。
4. 逐段确认，直到没有未确认的新路段。

即使下拉框默认已经是“步行”，仍需要保存确认。用时可选；不知道实际用时就留空，不要编造。

删除地点或调整顺序后，系统会重新检查相邻关系。新形成的路段可能需要再次确认，不能假设旧设置仍然适用。

### 4.7 检查隐私并提交

提交前逐项检查：

- 路线来自本人实际 GPS 记录，而非系统演示路线。
- 名称等路线信息已经保存。
- 至少两个有序地点。
- 每个地点至少一张现场照片。
- 所有相邻地点之间的交通方式已经保存确认。
- 裁剪后仍有可公开轨迹。
- 路线、地点说明和照片中没有不希望公开的住宅、办公地点或个人信息。

然后：

1. 找到“发布前隐私预览”。
2. 阅读说明并勾选隐私确认。
3. 点击“提交公开审核”。
4. 等待成功提示，状态应变为“审核中”。
5. 等待管理员处理，审核前其他普通用户看不到这条路线。

公开 GPS 会从起终点各裁剪约 150 米；打卡点和照片不会因此自动遮挡，仍需逐一核对。原始 GPS 不会因公开发布而对访客开放。

若提示冲突，说明路线版本可能已被其他页面修改；先记下未保存内容，再刷新核对。若提示材料不全，按错误消息补齐照片、路段或轨迹。

## 5. 管理员如何审核

1. 退出普通账号，登录管理员账号。
2. 进入“我的”。
3. 找到“审核工具”，点“打开管理后台”。
4. 在“待审核路线”里点“检查路线详情”，核对轨迹、地点、照片和说明。
5. 返回后台，选择“通过”或“拒绝”；拒绝时填写原因。
6. 通过后，路线才会出现在发现和地图中。

作者在“行程 → 我的路线”查看状态。被拒绝的路线可修改并重新提交；系统目前没有邮件通知功能，请在页面内主动查看并与测试团队沟通。

管理员还可查看举报、下架对应路线并标记处理完成。下架用于撤销公开访问，不是删除原作者 GPS。

## 6. 账号 B 如何收藏和复刻

### 收藏与分享

1. 使用另一普通账号 B 登录。
2. 在“发现”中找到已通过审核的路线。
3. 点“收藏路线”，到“行程 → 已收藏”查看。
4. 点“分享”，使用系统分享或复制链接。

分享的是应用当前访问地址下的路线链接。`127.0.0.1` 是每个人自己的设备，不可直接发给同事访问；应先用可访问的局域网或受控 HTTPS 地址打开，再生成分享链接。GitHub 仓库地址也不是某条路线的体验链接。

### 按站点复刻

1. 在公开路线详情点“开始复刻”。
2. 查看当前目标、照片、路段交通方式和站点顺序。
3. 需要道路导航时，点“在外部地图中导航”。
4. 具备 HTTPS 和定位权限时，可点页面的 GPS/当前位置按钮，记录本次实际位置。
5. 真正到达后点“确认到站”，当前目标切换为下一站。
6. 需要休息时点“暂停”，之后点“继续”。
7. 逐站完成后，再点“完成复刻”。
8. 到“行程 → 复刻记录”查看进度和完成状态。

GPS 不会自动替你确认到站；手动到站不证明已经在现场。复刻使用原路线的固定版本，复刻者的数据不会改写原作者路线。

可以提前结束复刻，但结束不会自动补齐尚未确认的站点。路线撤回/下架后，旧公开内容和对应版本的访问会受限。

## 7. 如何管理自己的路线和账号

在“行程 → 我的路线”切换状态筛选：

| 状态 | 含义与常见操作 |
|---|---|
| 草稿 | 尚未提交，可编辑 |
| 审核中 | 已提交，等待管理员处理，暂不可编辑 |
| 已公开 | 审核通过，可被发现、收藏和复刻 |
| 未通过 | 可以修改草稿内容并重新提交 |
| 已撤回 | 作者撤回，公开链接不再提供原公开内容 |
| 已下架 | 管理员取消公开 |

当前编辑和提交只接受草稿或未通过状态；没有作者在界面中将撤回/下架路线直接恢复为草稿并重新上架的完整流程。

“删除我的账号”会停用账号、注销会话，并撤回其符合条件的路线；已有数据和历史关联仍保留，不是物理删除全部行程。

## 8. 常见问题与处理

| 现象 | 怎么处理 |
|---|---|
| Docker 命令提示无法连接 daemon | 打开 Docker Desktop，等引擎就绪，再执行 `docker compose ps` |
| 浏览器打不开 | 查看 `docker compose ps` 和日志，确认端口、绑定地址及服务健康；不要把 8000/8002 混用 |
| 手机打不开电脑的页面 | 同一 Wi-Fi，使用电脑局域网 IP；检查绑定地址、防火墙及访客网络隔离 |
| 手机显示需要安全连接 | HTTP 只能浏览；请按[HTTPS 设置](DEPLOYMENT.md#https)使用设备信任的证书 |
| 定位被拒绝 | 开启系统定位和浏览器站点位置权限，再点重试定位；必要时重新打开页面 |
| 定位精度较差 | 移至开阔位置，保持前台等待；异常精度的点可能不计入有效距离 |
| 只有线稿，没有道路 | 尚未配置高德，或加载/坐标转换失败；检查 Key、安全码和允许的域名，使用页面重试入口 |
| 刚开始走了但距离还没变 | 等待可用采样及服务端同步，查看精度、已保存点数和待同步点数 |
| 点了暂停/保存却没完成 | 检查待同步点与网络，等待服务端确认后重试；不要清除本机存储 |
| 发布提示公开轨迹不足 | 路线过短或有效点不足；两端裁剪后可能没有可公开区间 |
| 勾选隐私后仍不能提交 | 查看具体错误，确认每站照片、每段交通方式及路线信息已保存 |
| 别人看不到我的草稿 | 正常。只有审核通过的公开路线才允许访客和其他普通用户浏览 |
| 撤回后旧链接失效 | 正常，撤回用于限制旧公开内容继续被访问 |
| 换设备后找不到未同步点 | 已确认的服务端数据可登录查看；未上传点在原设备浏览器中，不会自动跨设备转移 |
| 离线后打不开路线列表 | 目前只缓存应用外壳，不缓存完整路线库或离线地图；联网后重试 |
| 忘记密码 | 当前没有找回密码界面；受控测试中请联系部署维护者，或重新注册测试账号 |

轨迹记录队列最多保留 2,000 个点，复刻队列最多 1,500 个点。达到上限会替换较早的待同步点，应尽快联网；它们不是无限容量或加密的私人存储空间。
